Hướng dẫn cài đặt nhanh

1

Tải bộ cài SoundsSource.dmg

Bấm nút tải ở đầu trang để tải bản đóng gói SoundsSource.dmg chính thức từ Releases.

2

Kéo thả vào Applications

Mở file DMG vừa tải về và kéo biểu tượng SoundsSource vào thư mục Applications trên Mac.

3

Cấp quyền Audio Capture

Khởi chạy ứng dụng lần đầu và chọn Allow khi macOS yêu cầu cấp quyền thu âm để tiến trình bắt tiếng hoạt động.

4

Sử dụng từ Menu Bar

Bấm biểu tượng sóng âm trên thanh Menu Bar ở góc trên màn hình để mở bảng điều khiển bất cứ lúc nào.

Mở ứng dụng lần đầu (Cảnh báo Unidentified Developer)

Vì ứng dụng được ký ad-hoc mã nguồn mở, macOS có thể hiển thị cảnh báo khi mở lần đầu. Bạn có thể mở nhanh bằng 2 cách:

• Cách 1: Chuột phải vào ứng dụng SoundsSource trong Applications → Chọn Open.

• Cách 2: Dán lệnh Terminal sau để gỡ cờ kiểm dịch cách ly:

xattr -dr com.apple.quarantine /Applications/SoundsSource.app

Tự biên dịch từ Mã Nguồn

Chạy các lệnh sau trong Terminal để tự build bản đóng gói DMG (Yêu cầu macOS 14.2+ & Xcode 16+):

git clone https://github.com/songoku-03/voice-macos.git cd voice-macos ./scripts/build_dmg.sh
