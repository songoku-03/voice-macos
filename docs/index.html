Tính năng nổi bật

Bắt (Capture) tiếng từng ứng dụng

Tách biệt luồng âm thanh tiến trình của bất kỳ ứng dụng nào đang chạy: Spotify, Chrome, Safari, Discord, game 3D hay VLC mà không ảnh hưởng tới các app khác.

Âm lượng & Mute độc lập

Khuếch đại âm lượng đến 200% hoặc tắt tiếng nhanh cho từng app riêng biệt.

Equalizer 10-band trực quan

Điều chỉnh đường cong âm sắc từ 32 Hz đến 16 kHz bằng đồ thị kéo thả mượt mà.

Định tuyến (Route) âm thanh linh hoạt

Đẩy âm thanh từng app ra thiết bị phát khác nhau: Nhạc Spotify phát ra AirPods Max, thoại Discord ra loa Studio Display.

Hướng dẫn cài đặt

1

Tải file đóng gói DMG

Nhấp nút tải ở đầu trang để lấy bản đóng gói SoundsSource.dmg chính thức từ Releases.

2

Kéo thả vào Applications

Mở file DMG vừa tải, kéo biểu tượng SoundsSource vào thư mục Applications trên Mac.

3

Cấp quyền Audio Capture

Khởi chạy ứng dụng lần đầu và chọn Allow khi macOS yêu cầu cấp quyền thu âm để tiến trình capture âm thanh.

4

Sử dụng từ Menu Bar

Nhấp vào biểu tượng sóng âm trên thanh Menu Bar để mở bảng điều khiển bất cứ lúc nào.

Gỡ cảnh báo Unidentified Developer (quarantine)

Vì app được ký chữ ký ad-hoc mã nguồn mở, macOS có thể hiển thị cảnh báo khi mở lần đầu. Bạn có thể mở nhanh bằng 2 cách:

• Cách 1: Chuột phải vào app trong Applications → chọn Open.

• Cách 2: Dán lệnh sau vào Terminal để gỡ cờ kiểm dịch cách ly:

xattr -dr com.apple.quarantine /Applications/SoundsSource.app

Tự biên dịch từ mã nguồn

Chạy các lệnh sau trong Terminal để build file DMG thành phẩm (Yêu cầu macOS 14.2+ & Xcode 16+):

git clone https://github.com/songoku-03/voice-macos.git cd voice-macos ./scripts/build_dmg.sh
